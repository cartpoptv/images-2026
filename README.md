# Images

Photos and screenshots for the reviews on [cartpop.tv](https://cartpoptv.github.io/), published with
GitHub Pages at `https://cartpoptv.github.io/images-NNNN/`.

The site engine reads the size of every image from `manifest.json`, which the publishing workflow writes
here.

The year `NNNN` in the name is the year the repository was created. A new one, named after the year it is
created in, starts only when this one grows too large.
